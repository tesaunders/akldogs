# Standardised locality mappings for Animal Management data

A collection of suburbs compiled from Animal Management data mapped to
their corresponding Local Boards and regions. Suburb names were not
consistent across separate datasets within the information release, so
this table makes it easier to aggregate suburb-level data to
higher-level Local Board and regional groupings in a more standardised
way.

## Usage

``` r
locality
```

## Format

Data frame with columns

- suburb:

  Suburbs contained within the datasets released by Animal Management.

- rfs_no:

  Local Boards with jurisdiction over the suburbs found in the Animal
  Management data.

- rfs_date:

  Auckland regions mapped to Local Boards, as defined by Auckland
  Council online.

## Source
